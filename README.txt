SUYOG DENTAL CLINIC WEBSITE

Files:
- index.html: website content
- styles.css: layout, responsive design, and animations
- script.js: mobile navigation, scroll reveal animations, year, and appointment enquiry form

Preview:
1. Keep all three files in the same folder.
2. Open index.html in a modern browser.
3. Works responsively on Android and iOS browsers, as well as desktop.

Before publishing:
- Add the clinic's WhatsApp number in script.js (clinicWhatsApp variable) if you want enquiries to open a direct clinic chat. Use country code without +, spaces, or punctuation, e.g. 91XXXXXXXXXX.
- Confirm clinic address, phone, hours, and service details.
- Images and Google Fonts load from the internet; local preview needs an internet connection for those assets.
- The enquiry form opens WhatsApp; it does not submit or store appointments automatically.
